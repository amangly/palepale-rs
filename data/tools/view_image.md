Open a local PNG, JPEG, GIF or WebP image so you can inspect its visual contents.
Use this for screenshots, diagrams and other image files instead of reading binary
bytes through the shell. Pass an absolute path or a path relative to the project.
The image is attached to the next model request and retained in the session.
Read permissions apply. Files larger than {image_max_bytes} bytes are rejected;
use a smaller image or crop first. Requires a model with image input support.
